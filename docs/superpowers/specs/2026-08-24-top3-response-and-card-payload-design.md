# Top-3 回复与商品卡片数据设计

## 目标

当检索到三款商品时，推荐文字必须明确覆盖三款；SSE 商品卡片携带完整摘要字段，并继续使用现有商品详情页获取完整资料。

## 方案

回复 Prompt 使用编号 1/2/3 结构，要求每项含名称、准确价格和一句匹配理由。回复校验按候选商品逐项验证；漏任一款时回退到确定性 Top-3 模板。

SSE `products` 条目返回 Android `Product` 模型所需的 `product_id`、标题、品牌、品类、子类、价格、图片、SKU 与简介字段。卡片点击保留既有 `product_id` 导航；详情页通过 `/api/products/{product_id}` 加载 FAQ、评价等完整内容。

## 非目标

不改变 Android 导航，不在 SSE 中传输完整 FAQ/评价，不改变检索或评分数量。
